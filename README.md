# software-project
# Учебный проект по программной инженерии

Проект создан для изучения разработки программного обеспечения
с использованием GitHub.

## Цели проекта

- изучить работу с Git-репозиториями;
- организовать командную работу;
- использовать Issues и Projects;
- подготовить проектную документацию;
- изучить возможности GitHub Wiki.

## Команда

Проект выполняется учебной группой в рамках лабораторных работ.
